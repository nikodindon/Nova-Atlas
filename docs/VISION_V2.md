# Nova Atlas V2 — vision

Référence initiale : `dev@71937360d4e8d776a3cc88ad2ff7b6f58e51bff0`.
Le blueprint du 2 novembre 2026 fourni par le propriétaire guide ces décisions.
Ce document décrit une cible, pas les capacités déjà livrées.

Moteur autonome d'information et de radio, multilingue, traçable, configurable
par interface et installable sur Linux par Docker Compose. Préserver collecte,
extraction, résumés, éditions, rapports, posts, bulletins multivoix, archives et
compatibilité Android. Une indisponibilité LLM ne bloque pas la navigation ; une
panne TTS doit conduire à une reprise ou un programme de secours.

Un administrateur au départ. Ni atlas géographique, ni comptes multiples,
plateforme de journalistes, service commercial ou réécriture Android dans cette
première migration. Source originale, dates distinctes et provenance conservées.
Les images demandent une autorisation/licence : Open Graph ne confère aucun droit.
Toute illustration IA sera identifiée comme telle.

Pas de GPU obligatoire. Serveur primaire Linux Mint : Ryzen 5 1600 AF, 32 Go,
GTX 1650 Super 4 Go ; laboratoire facultatif : i5-8300H, 16 Go, GTX 1050 4 Go.
Windows pilote ; Tailscale sert l'administration privée sans IP codée en dur.
Les smartphones serviront aux tests Android dans un sprint ultérieur.
Les capacités GPU TTS devront être mesurées, jamais supposées.

Acceptation V2 : installation neuve documentée, restauration vérifiée, API stable,
administration protégée, collecte récupérable, coûts maîtrisés, radio sans perte
silencieuse et parcours responsive accessible. Chaque étape reste réversible.
